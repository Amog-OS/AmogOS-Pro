# AmogOS 2.x Pro

### Current Version: AmogOS 2.1 Pro
**SYSTEM REQUIREMENTS**
- Minimum 2-4 gb of RAM
- At least 32gb of disk space
- preferably a network
- a fairly recent graphics setup (within the past 18 years)

## CURRENT CHANGELOG:

> These are the patch notes for the latest version of *AmogOS 2.x Pro - Debian* as of 3/11/26.

**AmogOS App Store**
- Optimization and various fixes to minimize resource usage and increase peformance.
- Fix issues regarding installation of apt related packages and appimages.
- Improvements to update page now with flatpak, appimages and apt organised with options to manage apt related stuff.
- Installed apps installed with apt that are broken can now be repaired usign the new Fix option.
- Fixed major issue with programs such as vlc, krita and more not launching.

**KDE**
- Optimised to use less ram and resources

**System**
- Added `amogos-credits` which credits the devs of AmogOS 2.1 Pro.
- Cleaned up and modified system info files
- Ensured Fallback Installer and AmogOS Installer don't remain after installation.

**AmogOS Installer**
- Patches to stabilise online installation.
- Better optimization to ensure everything in Installer runs smooth and uses a low amount of ram.
